# FastAPI CI/CD Project

This project implements a full CI/CD pipeline using:

✅ GitHub Actions  
✅ Docker & Docker Hub  
✅ AWS EC2 Deployment  
✅ Automated testing with pytest  

### Features

- Build Docker images in CI
- Run automated tests
- Push image to Docker Hub
- SSH into EC2 and deploy automatically
- Health check verification after deployment

This README was added to trigger the CI/CD workflow.
